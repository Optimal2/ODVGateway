## Changes Since v0.1.39

A hardening release for the release process itself. An independent review of v0.1.39 found real gaps in it; this closes them. The gateway's runtime behaviour is unchanged.

- **The release gate now runs the unit tests.** It did not, and that mattered: publishing pushes with `--no-verify`, so the tests were skipped locally and first ran in the workflow *after* the tag was public. A failure there leaves a public tag with no release and no sanctioned way back, since retagging by hand is explicitly forbidden.
- **The release refuses more of what would produce a broken release.** Previously only "commits not pushed" was checked, and a missing upstream made that check pass silently. A detached HEAD, a release cut from a feature branch, or a local `main` behind origin all got through — the feature-branch case would have published a release from a commit that was never on `main`. Branch, upstream, ahead and behind are now all checked explicitly.
- **Existing tags are checked on origin, not just locally.** A tag already on origin previously surfaced only when the tag push was refused, after the release commit was already published.
- **A failed release says what it left behind.** Each step reports what exists and the exact command to undo or finish it. The tag-push failure is the important one: the commit is already on origin at that point, so the fix is to push the tag, not to reset.
- **The workflow's build-configuration input works.** It was present in the UI but dead — the build hardcoded Release. Dispatch runs now honour it, while a tag always builds Release so a mistyped dropdown cannot publish a Debug build.
- Corrected documentation that contradicted the process: the README still described the old manual proposal including hand-tagging, `docs/DEV-SETUP.md` said the script never publishes, and the version validator printed a claim about assembly versions that stopped being true when `<Version>` was introduced.

## Upgrade Guidance

No action is required. The published archive is equivalent to v0.1.39; only the process that produces it changed.
